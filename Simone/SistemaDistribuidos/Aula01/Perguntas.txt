2. O que acontece se o servidor falhar?

Desenhe a nova arquitetura proposta.

1: a sobrecarga de pedidos feitos a uma única maquina, tornando impossível que um único servidor permita funcionamento pleno

2: se o servidor falha todo o sistema deixa de funcionar já que como único ele mantem todos os serviços funcionando, uma falha desse único servidor significa uma falha total

3: poderia, o servidor único e um gargalo gritante. simplesmente aumentar a quantidade de maquinas aumentaria o processamento melhorando a velocidade e decentralizaria diminuindo o risco de falhas

4: na nossa situação de uma única maquina ele seria mais um incrível ponto de falha, mas também poderia criar uma mascara ip única para o servidor, em situação ideal aumentando a quantidade de maquinas ele criaria uma conexão entre essas maquinas para que trabalhassem juntas de forma que para o cliente parece haver apenas um servidor
